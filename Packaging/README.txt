More Network Capacity

中文

将《城市：天际线》一代的网络节点和路段容量提高到 65,024。

安装：将整个 MoreNetworkCapacity 文件夹复制到游戏的本地模组目录：
%LOCALAPPDATA%\Colossal Order\Cities_Skylines\Addons\Mods
在内容管理器中启用本模组，并确保已安装并启用 Harmony。
请避免同时启用本模组的本地副本和创意工坊副本。

使用前请备份存档。超过原版网络容量的存档需要保持本模组启用。
遇到问题时，可在本模组选项中导出诊断 ZIP；分享前请检查其中的日志和路径信息。

English

Raises network node and segment capacity to 65,024 in Cities: Skylines.

Installation: copy the complete MoreNetworkCapacity folder into:
%LOCALAPPDATA%\Colossal Order\Cities_Skylines\Addons\Mods
Enable the mod in Content Manager, with Harmony installed and enabled.
Avoid enabling both a local and a Workshop copy of this mod.

Back up your saves before use. Saves exceeding vanilla network capacity require
this mod to remain enabled. To report a problem, export a diagnostic ZIP from
the mod's options. Review its logs and file paths before sharing.

Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=3814019901
Source and issue reports: https://github.com/untouchable3/MoreNetworkCapacity
